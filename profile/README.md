# Tabgach · 桃花石

**Chinese-heritage ideas, engineered.**
传统的底子，工程的做法——认知架构研究、术数引擎，与两者之间的工具与文学。

> **Tabgach（桃花石）** 是中世纪突厥与伊斯兰文献对中国的称呼（源自拓跋）。
> 取它作名，因为它既是"中国"这个文明的名字，又不绑定任何具体朝代或领域——
> 装得下研究、术数、工具与文学。

## 项目 / Projects

### 🧭 术数引擎 · Metaphysics engines
- **[tianji](https://github.com/tabghach/tianji)** — 天机测算：易经六爻 / 奇门遁甲 / 紫微斗数
  三引擎排盘。零第三方依赖的纯 Python 历法与天文底座（VSOP87 太阳黄经、真朔精化、
  定朔定气农历与无中气置闰）；122 项测试对照 lunar_python / kinqimen / iztro 金标准交叉验证；
  含 CLI 与自包含 HTML 排盘图。

### 🛠️ 开源工具 · Open-source tools
- **[dsh-privacy-watchdog](https://github.com/tabghach/dsh-privacy-watchdog)** —
  AI 代理会话级隐私与权限看门狗：执行前拦截每个动作、按本地规则判定、
  暂停会话等待 allow/rollback/cancel。纯 Python 核心，零依赖。
- **[hotspot-pulse](https://github.com/tabghach/hotspot-pulse)** —
  热点流量预测与情绪分析流水线：RSS/GDELT 数据源、阻尼趋势预测、力导向热力网图
  （纯标准库，零依赖可离线跑）。
